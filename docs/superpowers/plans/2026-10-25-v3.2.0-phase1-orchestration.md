# v3.2.0 Phase 1: API Orchestration & Static Loading Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement automatic API process management and static asset loading in the Electron shell to eliminate the need for manual dev server startup and port dependency.

**Architecture:**
- The Electron main process will spawn the API process as a child.
- A health check mechanism will verify the API is running before the frontend loads.
- In production, static assets will be served directly from the disk using a custom protocol or `electron-serve`.
- API URLs will be dynamically provided to the frontend via IPC.

**Tech Stack:**
- Electron, Node.js `child_process`
- `axios` (for health checks)
- `electron-serve` (or custom protocol handler)

- [ ] **Step 1: Create API process manager**
Create a utility to spawn, monitor, and kill the API process.

```typescript
// apps/desktop/src/main/api-process.ts
import { spawn, ChildProcess } from 'child_process';
import path from 'path';
import { app } from 'electron';
import { logger } from './logger.js';
import { config } from './config.js';

let apiProcess: ChildProcess | null = null;

export async function startApiProcess() {
  if (apiProcess) return;

  const isDev = !app.isPackaged;
  // In dev, we might still want to use the dev server, but for orchestration we spawn it
  // For now, let's assume we spawn the built api or use tsx in dev
  const apiRoot = path.join(app.getAppPath(), '../../apps/api');
  
  logger.info(`Starting API process at ${apiRoot}`);

  const cmd = isDev ? 'pnpm' : 'node';
  const args = isDev ? ['--filter', 'api', 'dev'] : [path.join(apiRoot, 'dist/main.js')];

  apiProcess = spawn(cmd, args, {
    cwd: path.join(app.getAppPath(), '../..'),
    env: { ...process.env, PORT: config.api.port.toString() },
    shell: true
  });

  apiProcess.stdout?.on('data', (data) => {
    logger.info(`[API] ${data.toString().trim()}`);
  });

  apiProcess.stderr?.on('data', (data) => {
    logger.error(`[API-Err] ${data.toString().trim()}`);
  });

  apiProcess.on('close', (code) => {
    logger.warn(`API process exited with code ${code}`);
    apiProcess = null;
  });
}

export function stopApiProcess() {
  if (apiProcess) {
    apiProcess.kill();
    apiProcess = null;
  }
}
```

```typescript
// apps/desktop/src/main/windows.ts
import axios from 'axios';

async function waitForApi(url: string, maxRetries = 10): Promise<boolean> {
  for (let i = 0; i < maxRetries; i++) {
    try {
      await axios.get(`${url}/health`, { timeout: 1000 });
      return true;
    } catch (e) {
      await new Promise(resolve => setTimeout(resolve, 1000));
    }
  }
  return false;
}

// Update createMainWindow to wait
export async function createMainWindow() {
  // ...
  const apiReady = await waitForApi(`http://localhost:${config.api.port}`);
  if (!apiReady) {
    logger.error('API failed to start in time');
  }
  mainWindow.loadURL(config.web.url);
}
```
