# v3.2.0 Phase 2: MariaDB Bundling & Automated Deployment Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Achieve zero-config database setup by bundling MariaDB binaries and managing its lifecycle within the Electron shell.

**Architecture:**
- Use platform-specific MariaDB binaries (bundled via `electron-builder` extraResources).
- Implement `db-process.ts` in Electron main process to manage MariaDB lifecycle.
- Automatically initialize the database (run `mysql_install_db`) if the data directory is empty.
- Dynamically inject the local database URL into the API process.

**Tech Stack:**
- MariaDB Binaries
- Node.js `child_process`, `fs`
- Electron `app.getPath('userData')`

```json
// apps/desktop/package.json
{
  "build": {
    "extraResources": [
      {
        "from": "bin/${platform}",
        "to": "mariadb-bin",
        "filter": ["**/*"]
      }
    ]
  }
}
```

- [ ] **Step 2: Create binary path utility**
Implement a helper to get the path to MariaDB binaries in both dev and prod.

```typescript
// apps/desktop/src/main/db-paths.ts
import path from 'path';
import { app } from 'electron';

export function getMariaDBBinPath() {
  const isDev = !app.isPackaged;
  if (isDev) {
    // In dev, assume binaries are in a specific local folder or path
    return path.join(app.getAppPath(), '../../bin', process.platform);
  }
  return path.join(process.resourcesPath, 'mariadb-bin');
}

export function getMariaDBDataPath() {
  return path.join(app.getPath('userData'), 'db-data');
}
```

### Task 2: MariaDB Process Manager

**Files:**
- Create: `apps/desktop/src/main/db-process.ts`
- Modify: `apps/desktop/src/main/index.ts`

- [ ] **Step 1: Implement MariaDB manager**
Handle initialization, startup, and shutdown of the MariaDB process.

```typescript
// apps/desktop/src/main/db-process.ts
import { spawn, ChildProcess } from 'child_process';
import fs from 'fs';
import { logger } from './logger.js';
import { getMariaDBBinPath, getMariaDBDataPath } from './db-paths.js';

let dbProcess: ChildProcess | null = null;

export async function initDatabase() {
  const dataPath = getMariaDBDataPath();
  if (!fs.existsSync(dataPath)) {
    logger.info('Initializing MariaDB database...');
    fs.mkdirSync(dataPath, { recursive: true });
    // Run mysql_install_db or equivalent for the platform
    // spawn(path.join(binPath, 'mysql_install_db'), [...])
  }
}

export async function startDbProcess() {
  if (dbProcess) return;
  await initDatabase();

  const binPath = getMariaDBBinPath();
  const dataPath = getMariaDBDataPath();

  dbProcess = spawn(path.join(binPath, 'mariadbd'), [
    `--datadir=${dataPath}`,
    '--port=3307', // Use a non-standard port to avoid conflicts
    '--skip-networking=0',
    '--bind-address=127.0.0.1'
  ]);

  dbProcess.stdout?.on('data', (data) => logger.info(`[DB] ${data}`));
  dbProcess.stderr?.on('data', (data) => logger.warn(`[DB-Log] ${data}`));
}

export function stopDbProcess() {
  if (dbProcess) {
    dbProcess.kill();
    dbProcess = null;
  }
}
```
