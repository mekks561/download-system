# DM Download Manager Roadmap (v3.3.0+)

## 1. 核心愿景
从「桌面壳程序」进化为「企业级分布式下载基础设施」，深化 AI 驱动的治理能力与插件化生态。

---

## 2. v3.3.0: 工业化 2.0 - 智能治理 (Smart Governance)
**目标**：提升海量任务下的管理效率。
- **智能配额 (Smart Quota)**：
  - 基于用户行为画像的动态存储配额调整。
  - 自动识别并回收低活跃用户的闲置空间。
- **AI 智能去重 (Deduplication)**：
  - 基于向量相似度的资源探测，防止重复下载。
  - 提供一键清理建议。
- **自动归档 (Auto-Archiving)**：
  - 冷热数据分析：长时间未访问的文件自动压缩或迁移至廉价存储（如 NAS 存档区）。
  - 提供透明的「按需恢复」能力。

## 3. v3.4.0: 弹性集群 - 分布式 2.0 (Elastic Cluster)
**目标**：增强高可用与横向扩展能力。
- **Worker 动态扩容**：
  - 支持一键拉起 Docker Worker 并自动加入 Master 集群。
  - 负载均衡算法优化（地理位置感知、磁盘寿命感知）。
- **任务热迁移 (Live Migration)**：
  - 在不中断下载的情况下，将任务从一个 Worker 迁移到另一个（断点续传无缝衔接）。
- **监控与告警**：
  - 集成 Prometheus/Grafana，提供全集群 QPS、磁盘 I/O、网络带宽监控。

## 4. v3.5.0: 开放生态 - 插件市场 (Plugin Marketplace)
**目标**：建立社区驱动的功能扩展体系。
- **官方插件市场**：
  - 提供 UI 界面浏览、搜索、一键安装插件。
  - 插件签名与沙箱安全增强。
- **SDK 深度扩展**：
  - 支持插件注入自定义 API 路由与前端 UI 组件。
  - 支持「后置处理」管道（如：下载完成后自动重命名、自动刮削元数据、推送到特定网盘）。
- **首批核心插件**：
  - `MetaScraper`：自动抓取电影/番剧元数据并生成 NFO。
  - `CloudSync`：下载完成后自动上传至阿里云盘/Google Drive。

## 5. v4.0.0: 未来视界 - 极致体验 (Next-Gen UX)
**目标**：重塑下载管理器的交互范式。
- **全平台一致性**：
  - 正式发布移动端 App（React Native），支持远程管理与推送到家下载。
- **零信任安全 (Zero Trust)**：
  - 全面切换至 OAuth2/OIDC 认证体系。
  - 所有分享链接支持端到端加密（E2EE）。
- **全局搜索 2.0**：
  - 跨集群、跨存储介质的全文检索。
  - AI 自然语言对话式交互：「帮我找出上个月下载的所有 4K 电影并移动到存档区」。

---

## 6. 技术债与优化 (Ongoing)
- **体积优化**：精简 MariaDB 捆绑包与 Electron 运行时体积。
- **安全性**：引入代码混淆与二进制保护。
- **性能**：主进程与后端 API 间的通信协议转向 gRPC 或 WebSocket 紧凑二进制格式。
