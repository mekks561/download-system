# Electron 外壳重建 MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal**: 以"薄壳"方向在 v3.1.0 交付 Electron 桌面壳：BrowserWindow 双窗口（web 3000 + gm-admin 3100）、preload IPC bridge、托盘/菜单/单实例锁。壳**不**编排 API/MariaDB 进程（v3.2.0 半编排、v3.2.1 mariadb-bin 捆绑）。

**Architecture**: `apps/desktop` 新增 workspace app（Electron 32 + TS + vite-electron），壳进程只做窗口管理 + preload；API/web/gm-admin 保持独立 dev server，壳 `loadURL` 指向它们。打包进 v3.2.0，v3.1.0 dev-only。

**Tech Stack**: Electron 32（内嵌 Node 25.2.1，覆盖项目 `engines.node >=20`）、TypeScript 6、Vitest、electron-vite。

**Spec ref**: `docs/superpowers/specs/2026-10-12-electron-design.md`（决策文档，Accepted 状态）

**Branch**: `feature/v3.1.0/s5-shell`（单分支，Task 0-5 全部在同一分支实现）

## 关键风险与对策

| 风险 | 对策 |
|---|---|
| Electron 主进程 fork Worker 行为异常（spec L709 标注） | **PoC 已验证全绿**（2026-10-12），SandboxRunner 零改动。v3.1.0 壳不编排插件宿主，插件仍在独立 API 进程跑 worker_threads，进一步隔离风险 |
| Electron 打包体积 | v3.2.0 再处理；v3.1.0 dev-only |
| electron-builder 跨平台 native deps（mariadb-bin） | v3.2.0 mariadb-bin 捆绑，v3.1.0 不管 |
| 壳与 web/gm-admin dev server 启动顺序 | BrowserWindow 加重试（did-fail-load 或 2s 定时器重试 3 次）；用户手动起三个 dev server 或 `pnpm dev:all` 渐进 ready |
| gm-admin 与 web 路由冲突 | 已澄清：两个独立 BrowserWindow 各自 loadURL，完全不冲突，gm-admin BrowserRouter 无需 basename |
