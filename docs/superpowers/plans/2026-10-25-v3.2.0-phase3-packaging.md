### Task 2: Auto-Update Implementation

**Files:**
- Modify: `apps/desktop/src/main/index.ts`
- Create: `apps/desktop/src/main/updater.ts`

- [ ] **Step 1: Create updater module**
Implement basic check for updates and event listeners.

```typescript
// apps/desktop/src/main/updater.ts
import { autoUpdater } from 'electron-updater';
import { logger } from './logger.js';

export function initUpdater() {
  autoUpdater.logger = logger;
  
  autoUpdater.on('update-available', () => {
    logger.info('Update available.');
  });
  
  autoUpdater.on('update-downloaded', () => {
    logger.info('Update downloaded; will install now');
    autoUpdater.quitAndInstall();
  });

  autoUpdater.checkForUpdatesAndNotify();
}
```

- [ ] **Step 2: Integrate updater into main entry**

```typescript
// apps/desktop/src/main/index.ts
import { initUpdater } from './updater.js';

app.whenReady().then(() => {
  // ... after windows are created
  if (app.isPackaged) {
    initUpdater();
  }
});
```
